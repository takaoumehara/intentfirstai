Context Brain · 3 Layers

家族の記憶を、
3つの速度で持つ。

AIに名前をつけるのではなく、家族の記憶を1つ持つ。

記憶は3層。変わらない部分、ゆっくり育つ部分、今この瞬間の部分。

→ スペースキーで1層ずつ開く

L1 Identity 変わらない
名前。アレルギー。プロナウン。言語。価値観。
1年前に登録したアレルギーは、今日も有効だ。
L2 Accumulated Learning 日々育つ
月曜は送り迎え。冬は魚を控える時期。
生活のリズムから、パターンが生まれる。
L3 Right Now 今この瞬間
移動中。手が空いていない。緊急。
8つのToken が、リアルタイムで状況を読む。
L1 — Identity Card

家族のDNA。
全エージェントが、ここから始まる。

5人それぞれの、変わらない情報。
プロナウン、アレルギー、言語。

Finance Agent も、Education Agent も、Travel Agent も、まずここを読む。

1つ書けば、全員に届く。

L3 — 8 Context Tokens

今、この瞬間の
Mai を読む8つの目盛り。

移動中か。忙しいか。誰と一緒か。
画面はスマホか冷蔵庫か。今これは「やれること」か。

8つの Token がリアルタイムで動き、AIの振る舞いを変える。

L3が変われば、出る答えも変わる。

1 Brain · 5 Agents

1つの記憶から、
5つのエージェントへ。

家族のBrainは1つ。エージェントは5つ。デバイスは無数。

Finance は家計だけを見る。
Education は子供の学習だけを見る。
Calendar だけが、全エージェントを横断する。

何を共有し、何を分離するか。それが設計だ。

Disclosure Matrix

「何を分離するか」
こそが、信頼を生む。

Finance Agent は、子供の成績を読まない。
それは制限ではなく、設計の選択。

5つのエージェント × 5つの情報ドメイン。
25の境界を、設計する。

Translation Layer · Axis 1

同じ事実を、
4人に違う深さで翻訳する。

Kiran が健康診断で、肝機能の数値を指摘された。

本人には、データの全文。
妻 Mai には、要旨と「夕食を調整」のアクション。
娘 Aoi には、「最近パパはノンアル選んでる」という観察だけ。
幼い Leo と Sota には、何も。

これは権限管理ではない。意味の翻訳だ。

月曜日 · 朝7時

誰も指示していない。
でも、家は動いている。

冷蔵庫が、今日の弁当を3つ提案する。
スマホに通知が1件。「送り迎えが30分ずれた」。
子供部屋では、復習シートが昨夜のうちに印刷されている。

家族の生活が、文法になった。

Substitution Modes

同じ「ヨーグルト」
でも、4通りの文法がある。

Kiran は Flexible。同等品なら替えていい。
Aoi は Exploring。新しいdairy-freeを試している途中。
Leo は Exact + Surprise。いつものか、新しい挑戦か。
Mai は Auto。決まったブランド、自動で。

Brainは家族を1人に均さない。4通りの好みを、別々に覚える。

Connective Disclosure · Axis 2

3人が、同じ作品の
軌道に入っている。

Aoi は Netflix で、その作品のアニメを観ている。
Kiran は Kindle で、原作マンガを読んだばかり。
Sota は、その主題歌をずっと口ずさんでいる。

Spotify はプレイリストを共有できる。
Netflix は視聴履歴を共有できる。
Kindle は読書履歴を共有できる。

3つを横断して「同じ世界にいる」と気づけるのは、Brainだけだ。

Care Architecture · 緊急

娘が喘息発作。
画面に残ったのは、1つ。

Mai は運転中だった。Cognitive Load は MAX。

Home Agent も、Finance Agent も、Education Agent も—
全員が、黙った。

画面に残ったのは「養護教諭に電話する」、ボタン1つ。
UIが、認知負荷に合わせて、収縮した。

Care Architecture · Cascade

Mai が選んだのは1つ。
AIが動かしたのは10個。

Mai が「電話する」を選んだ瞬間、裏で全エージェントが動いた。

自動で実行：パートナーに通知、夕食を「遅め帰宅」に調整、Finance/Education のタスクを停止。

承認待ち：Zoom会議の延期文、医師への状況報告のドラフト。

緊急度が、全エージェントの優先順位を、一瞬で書き換える。

L1 Identity update
娘が、Mai に打ち明けた。
Mai はそれを、Brain に伝えることにした。

性自認が更新された。

娘の部屋の照明が、少し変わった。
Education Agent が話しかける言葉が、少し変わった。
Home Agent が提案する内容が、少し変わった。

誰もそれに気づかなかった。
それが、正しい設計だ。
Autonomy Timeline · 12 months

12ヶ月後、関係は
ドメインごとに違っていた。

料理は Omakase。任せていい。
スケジュールは Infrastructure。意識しない。
子供の教育は Collaborator。一緒に考える。
財務は Steward。自分でコントロールする。

同じBrain、4つの違う関係。
積み上げた信頼が、ドメインごとに、決める。

Family Archive · Axis 3

家族が積み上げるのは、
1種類の記憶じゃない。

Memories：今すぐ、全員で。
Recipes：料理する人にだけ開く。
Parent-as-Person：子が20歳になったら解錠される。Kiran の若い頃の日記、Mai の初めての職場の悩み。
Family Stories：Aoi が高校選びに悩んだ時、似た決断の記録が浮上する。
Skills：自転車を教えた日。分数を説明したメモ。

伝えたいけど伝えきれないものを、AI が、時間をかけて、運ぶ。

Project 01 · Close

設計するのは、AIではない。
家族が生きる、文脈だ。

L1（誰か）。L2（どう生きているか）。L3（今、何が起きているか）。
この3層がある家族は、AIに名前をつけなくていい。

料理ではOmakase。財務ではSteward。緊急時にはInfrastructure。
同じBrain、違う関係。それが Dial の設計だ。
