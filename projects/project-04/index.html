Product model

Not a chatbot. A decision memory layer.

Enterprise Context Brain is not another place to talk to AI. It is the memory layer beneath the places where work already happens. Atlas Portfolio, Figma, Slack, Jira, Drive, meeting views, and onboarding screens all call the same Brain contract: read what matters, write what was decided, subscribe to what changes.

Primary surface
Portfolio Command
Priya's command surface for proposals, active projects, held work, intent drift, and cross-Brain reasoning.
Embedded surfaces
Figma, Slack, Jira, Drive
The Brain appears inside the tool where the decision is already happening. These are surfaces, not separate Brain products.
Ambient surfaces
Notifications, digests, side panels
Relevant context arrives only when Autonomy and Disclosure allow it. Ambient does not mean another inbox.

Product boundary The product is not the screen. The product is the contract that lets every screen share memory.

Chapter 01
Five Brain Architecture.
Five Brain Architecture

Many Brains. One decision memory layer.

Org Brain holds company facts. Brand Brain holds judgment DNA. Research Brain holds customer evidence. PMB reads across them to propose what should start, hold, or stop. Project Brain carries one project's intent, learning, and live state.

The user does not choose among these Brains first. The interface resolves the right scope for the work. Every Brain keeps the same three-layer anatomy: Identity, Learning, and Now.

Org Brain
Foundation
Permanent · shared by all

Org chart, policies, glossary, history. The unchanging ground every other Brain reads.

Brand Brain × N
Judgment DNA
B2C + B2B · parallel instances

Brand voice, visual judgment, ethical stances. Separate instance per brand; Leena holds authority over all.

Research Brain
Signal layer
Accumulates · refreshes live

Years of studies in Learning. Live sales, support, NPS in Now. Extracts relevant fragments into new Project Brains at kickoff.

At project kickoff, Research Brain releases a scoped fragment — only the user signals, competitive data, and behavioral patterns relevant to that brief — directly into the new Project Brain. The Project Brain doesn't query Research; it inherits a curated slice and evolves from there.

Project Master Brain (PMB)
The strategist
Reads all Brains · proposes, never decides

Reads Research × Brand × Org capacity × past project patterns. Drafts proposals when signals arrive. Spawns Project Brains. Never auto-decides — the decision is always Priya's.

Project Brain × N
Time-bound
Execution
Born at kickoff · dies at close

Carries Identity (intent) + Learning (decisions) + Now (sprint state). Graduates on close — Now evaporates, Learning dissolves into Org Brain, Identity archives.

Disposable Brain · Enterprise scale

Project Brains are time-limited: born at kickoff, dissolved at close. At enterprise scale, a crisis can spin up an emergency variant — a Hurricane Brain — instantiated within hours to handle a surge event the main system was never sized for.

When Hurricane Helene overwhelmed a claims center at 3 a.m., a temporary Claims Brain was spawned, sandboxed, and scaled to 300+ concurrent claims across six sub-agents under a single human supervisor. Seventy-two hours later, the crisis passed: the Brain committed its learned patterns (flash-flood claims require photo pre-auth) to the permanent Org Brain, dissolved its sandboxed database, and ceased to exist. This is the enterprise analog to the Trip Brain in Project 01 — the same lifecycle, at disaster scale.

Chapter 05
Over Time — Arman inherits.
12 weeks · Autonomy Dial per domain

The team lets the Brain do more — per domain, at different rates.

Week 1 · Suggest
The Brain shows up at standup.

Reads Identity Layer aloud. Suggests sprint goal. Priya accepts, rewrites, or declines — all three are teaching signals.

Week 4 · Confirm
Drafts start landing.

UI-direction prompts produce drafts worth reviewing. Maya accepts one in three. The Learning Layer remembers which taste won.

Week 8 · Notify
Standup moves into the Brain.

Meeting Brain captures everything. Decision log, not transcript. Dev stops taking notes.

Month 3 · Auto (per domain)
Four dials, four settings.

Research = Auto. Brand = Confirm (Leena's). Code = Notify. Intent = Suggest — that one stays human.

Stakeholder Autonomy Matrix
Traditional enterprise tools use ACL booleans — can or cannot access. Context Grammar uses confidence-graduated Autonomy: the Brain adjusts how much it acts versus asks based on learned trust, per person, per domain. Each cell in the matrix isn't a permission flag — it's an Autonomy stage wired to the Brain's confidence telemetry. Maya can be Auto on UI direction and Leena can hold Veto on brand at the same moment, across the same project.

Chapter 06
What changed.
How this was made · design refusals

Two cuts that sharpened the design.

D02 · cut Surveillance-style monitoring
Killed the per-person productivity score after one prototype review.
The team considered continuous background monitoring of each person's activity to feed the Brain. "Priya · 87% productivity this sprint" turned every interaction into surveillance. Replaced with Intent Match at the project level — explicit intent declaration by the user, not inferred from behavior streams. Measure the work, not the worker.
D06 · cut "The Brain as chatbot"
Cut the chat-with-the-Brain interface from PMB.
A chatbot interface was proposed for Project Master Brain interactions — ask it a question, get an answer. Rejected. The Brain isn't something you talk to; it's a memory layer that surfaces insights in-context, in Figma, in Slack, on the iPhone Brand-check screen. The central UI is not a message box. It is a set of decision surfaces backed by one memory contract. A chat box would have flattened the architecture into the wrong shape.
