Context Grammar · Project Brain Structure

Project Brain · 内部の3層構造

Project Brain は単一の箱ではない。L1 Intent · L2 Learning · L3 Right Now—3つの層で構成される。各層は持つ情報の性質が違い、プロジェクト終了時に違う宛先へ卒業する（Graduated Archive）。

この3層構造は Context Grammar の普遍則—家族Brain（P1）も旅行Brain（P2）も同じ構造を持つ。P4ではそれが組織の時限Brain に適用される。

L1 · INTENT 意図層 Why we're doing this
「なぜこのプロジェクトを作ったのか」
プロジェクトの原意 · 根本目的
主要な意思決定とその理由
スコープの境界線（何を作らないか）
譲れない原則 · 守るべき体験
Project Atlas · L1 Example
「迷いを歓迎する探索UI」—効率より発見の体験。2026-01 キックオフで Priya が定義。変わらないスコープ境界。
L2 · LEARNING 学習層 What we discovered
「このプロジェクトで何を学んだか」
ユーザー反応の傾向・発見されたパターン
チームの働き方・効果的な協働形式
技術的制約と回避策
仮説の検証結果（成功 · 失敗の両方）
Project Atlas · L2 Example
「ペルソナAは午後3時に離脱率が上がる」—Sprint 2 のユーザーテストから発見。探索UIにはこの時間帯の配慮が必要と判明。
L3 · RIGHT NOW 現在層 What's happening today
「今このスプリントで何が起きているか」
今週の優先度 · 未決事項
進行中のタスク · ブロッカー
直近の会議で出た話題
現在のチーム構成 · 役割配分
Project Atlas · L3 Example
「Sprint 4 · Intent Fidelity 監視導入中」—今週Priyaが取り組んでいる。Sprint 5 で決着予定。プロジェクト終了と共に意味を失う。
Graduated Archive · Exit Paths

プロジェクト終了時—3層は別々の宛先へ卒業する

L3 Right Now
↓
EVAPORATE 蒸発
今この瞬間の文脈は、プロジェクト終了の瞬間に意味を失う。保存する価値がない—次のプロジェクトには邪魔になる。だから蒸発する。
L2 Learning
↓
MERGE Org Brain へ統合
学びは組織の資産。次のプロジェクトの出発点を底上げする。Atlas で発見された「午後3時離脱」は、Research Brain に流れ込み、Orion のデザイン判断を静かに導く。
L1 Intent
↓
COMPRESS Atlas Archive へ永続保存
意図と主要決定の理由は、圧縮されて永続アーカイブへ。3年後、Priya が去っても「なぜ探索UIにしたか」の答えは残る。Archive Replay でスクラブ可能。
Universal Pattern · P1 との接続

この3層構造は Context Grammar の普遍則だ。家族Brain（P1）も、旅行Brain（P2）も、Project Brain（P4）も、全て Identity／Accumulated／Right Now の3層を持つ。何が L1 に入るかがドメインで違うだけ—家族なら「この家族の価値観」、旅行なら「この旅の目的」、プロジェクトなら「このプロジェクトの意図」。構造は1つ。
