連立方程式 — 2つのナゾを同時に解く

わからない数が2つ（xとy）あっても大丈夫。 ヒントの式も2つあれば、必ず1組の答えにたどり着ける。その「魔法のやり方」を体で覚えよう。

まずはイメージ：くだもの当てゲーム 🍎🍊

値段のわからないりんご🍎とみかん🍊。ヒントは2つ。さあ、1個いくら？

🍎🍎 ＋ 🍊🍊🍊 ＝ 320円
🍎 ＋ 🍊🍊 ＝ 190円
🍎 = ？
🍊 = ？

🍎をx、🍊をyと名前をつけると… 2x + 3y = 320 と x + 2y = 190。 これが「連立方程式」。次に解き方を2つ覚えよう。

🧠 数学うんちく #1 — 連立方程式は2000年前からある
じつは連立方程式、約2000年前の古代中国の数学書『九章算術』にもう登場してる。 お米の収穫を当てる文章題として解かれていたんだ。さらに、きみがこれから習う「加減法」を スゴ技に進化させたのが大数学者 ガウス。コンピューターが何百個もの式を一瞬で解くときも、 その仕組みはきみが今やる計算と同じ。 つまり——いま学ぶこの1ページは、最先端AIの計算とつながってる。
解き方 その1

加減法 — そろえて消す ✂️

同じ文字の数（係数）をそろえて、式どうしをたし算・ひき算すると、文字が1つ消える！

▶ ボタンで1ステップずつ
①　2x + 3y = 320 ②　 x + 2y = 190 ②×2　2x + 4y = 380 ①−②×2 で 2x が消える 　−y = −60 → y = 60 🍊 ②へ代入 → x + 120 = 190 x = 70 🍎　できた！
1

係数をそろえる

消したい文字を決める（ここはx）。②を2倍して、xの数を両方「2」にそろえる。

2

ひき算して消す

①−（②×2）。2x − 2x = 0 でxが消える。残るのはyだけ。

3

残った文字を解く

−y = −60 → y = 60。みかんは60円だ！

4

もう片方にもどす

yを②に代入してxを出す → x = 70。りんごは70円。

解き方 その2

代入法 — 1つを式ごとはめ込む 🧩

片方の式を「x =〜」の形にして、そのかたまりごともう片方に入れる。

1

かんたんな式を変形

②「x + 2y = 190」を x = 190 − 2y にする。

2

まるごと代入

①のxの場所に「190 − 2y」をはめ込む → 2(190 − 2y) + 3y = 320

3

計算して解く

380 − 4y + 3y = 320 → −y = −60 → y = 60 → x = 70。 加減法と同じ答えになる。やり方は2つ、ゴールは1つ！

💡 コツ：「x＝」や「y＝」の形がすぐ作れそうなら代入法、 係数がそろえやすいなら加減法。問題を見て速いほうを選べると上級者。

いちばんの山場

文章題 → 式に変える 3つの呪文 ✨

テストで点を落としやすいのはココ。でも手順はいつも同じだよ。

1

「？」に名前をつける

求めたいものを x・y にする。 「大人 x 人、子ども y 人」のように。

2

関係を2本の式に

「合計の人数」で1本、「合計の金額」でもう1本。 数えられる関係を見つけたら、それが式になる。

3

解いて、日本語で答える

連立を解いたら「大人7人、子ども5人」と単位つきで答える。これで満点。

三角形の合同 — 「ぴったり重なる」を証明する

2つの三角形が「形も大きさも完全に同じ（＝合同）」だと、どう示せばいい？ じつは3つのチェック項目のどれか1つを満たせばOK。まずは目で見て納得しよう。

アニメ：本当にぴったり重なるの？ 🎬

右の三角形を、回して・動かして、左にスッと重ねるよ。ボタンを押してみて。

重なったら「△ABC ≡ △DEF」。この「≡」が合同の記号だよ。

🧠 数学うんちく #2 — 証明は「ゲームのルール」みたいなもの
証明をはじめて作ったのは約2300年前のギリシャ人、ユークリッド。 彼の本『原論』は、聖書の次に世界で読まれた本とも言われる超ロングセラー。 証明のすごいところは——「なんとなく正しい」じゃなく「ぜったい正しい」を作れること。 サッカーがルールの上で成り立つように、数学はこの証明ルールの上で成り立ってる。 きみは今、その2300年前のゲームを遊んでるんだ。
最重要・暗記ポイント

合同条件は3つだけ 🃏

下のカードを押すと、どこが等しいか光るよ。声に出して覚えよう。

⚠️ ひっかけ注意
「2辺と間じゃない角」や「3つの角だけ」では合同を言いきれない。 角が3つ同じでも、大きさちがいの三角形（＝相似）がありうるからね。 だから合同条件は上の3つだけと覚えよう。
証明の書き方

証明は「型」にはめるだけ 📝

作文みたいに自由に書くんじゃない。下の5ステップの型に流しこむだけ。

1

仮定と結論を確認

「何が分かっていて（仮定）」「何を言いたいか（結論）」を最初にハッキリさせる。

2

どの2つの三角形か宣言

「△ABCと△DEFにおいて」と書きはじめる。

3

等しい所を3つ、理由つきで並べる

「仮定より」「共通だから」「対頂角は等しいから」など、根拠をそえて3つ書く。

4

合同条件を宣言

「2組の辺とその間の角がそれぞれ等しいので」→「△ABC ≡ △DEF」。

5

結論を書く

合同からいえること（対応する辺・角が等しい等）を書いて完成。

よく出る応用

平行四辺形は「合同の宝庫」 ◇

対角線を引くと、合同な三角形が現れる。だから平行四辺形の性質は、 合同の証明で次々と示せる。

✓

2組の対辺は等しい

向かい合う辺の長さが同じ。

✓

2組の対角は等しい

向かい合う角が同じ。

✓

対角線はそれぞれの中点で交わる

交点で半分ずつに分かれる。

✓

1組の対辺が平行で等しい→平行四辺形

逆向きの判定にも使える。

💡 証明の「等しい根拠」として「平行線の錯角は等しい」「共通の辺」が 超ひんぱんに出る。この2つは口ぐせにしておこう。
