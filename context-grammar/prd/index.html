Context Brain · PRD v1.0 · 2026

あなたのAIには、
記憶がない。

Context Brainは、AIに記憶の構造を与える。家族全員に対応した5つのBrain。6層のアーキテクチャ。npxコマンド一発で始まる。

OSS · MIT License ストレージ完全ローカル 推論は Claude API（V2 で Ollama 対応） V1 MVP · 2026 Q3

CH 01 · 01 — 問題

最先端のユーザーでも、
毎回一から説明している。

Obsidian + Claude Codeで最も進んだ使い方をしている人たちが何ヶ月もかけて手動で構築していること——それがContext Brainが自動でやることだ。

「The friction is no longer with Obsidian itself, but with the boundary between the vault and agent execution. The next unlocked is figuring out how to get agents tasked to run automatically.」

— Internet Vin（Greg Isenberg Podcast, 2026）

「My relationship with computers has evolved. I cannot believe that I can just be making notes and then all of a sudden this agent can scan through it and build things because of it.」

— Internet Vin

Vinは数ヶ月かけてスラッシュコマンドを自作し、毎日ノートを書き続けることで、ようやくAIが「自分のことを知っている」状態を作った。それは天才的な使い方だ。だが99.99%の人にはできない。

根本的な問題

AIに渡すコンテキストを、毎回一から説明している。家族全員分の記憶を、一人のエンジニアが手動で管理している。それは設計の問題だ。

CH 02 · 01 — シナリオ

「靴、どうしよう」
たった一文が、5つのBrainを動かす。

11歳のSotaがリビングで呟いた。このひとことに、Context Brainは5つのBrainを同時に読み、1つの答えを返す。

SOTA · 11歳 · リビング · 15:30 「靴、どうしようかな。」

Household Brain

家族の全体状況

今月の食費が予算より¥8,000オーバー。来週、家族旅行の出発あり。

Learning Layer → 予算・スケジュール読込

Person Brain · Sota

Sota個人の記憶

サッカー続行決定（先月確認）。現在のシューズは3サイズ前のもの。幅広タイプ。

Identity + Learning Layer読込

Domain Brain · スポーツ

スポーツ用品の知識

アシックスDS Light 4（幅広・サッカー少年向け）。定価¥12,800。今週セール中。

Learning Layer → 商品情報読込

Coordinator

3つのBrainを統合

予算制約 × Sota需要 × セール機会を照合。Autonomy Dial = Confirm（購買は要承認）。

AX Pattern: D1 Approval Gate + A2 Cognitive Scaling

Context Brain の返答

「Sotaくん、アシックスのDS Light 4（¥12,800）が今週セール中。サッカー続けるなら今がタイミング。先月の食費オーバーはあるけど、旅行前に買っておくほうがいいと思う。お母さんに確認してから注文します？」

Vinのセットアップでこれをやろうとすると、毎回スラッシュコマンドを手打ちし、3つのファイルを手動で開き、自分でコンテキストをつなぎ合わせる必要がある。Context Brainは、それを自動でやる。

CH 02 · 02 — アーキテクチャ

6層のスタック。
下から順に積み上げる。

L0が土台（.mdファイル）。L5が出口（テンプレート）。すでに実装済みの層が3つある。

L5

Templates

家族 / 企業 / 個人の初期設定パック。インストール後すぐ使えるBrain雛形。

L4

AX Pattern Engine

8つのContext Tokenを評価し、23のAXパターンを発火させる。SDK実装済み（TypeScript）

L3

Autonomy Dial + Disclosure Dial

AIがどこまで自動で動くか（Suggest → Confirm → Notify → Auto）。何をAIに見せるか（none → minimal → moderate → full）。

L2

Coordinator + SELECTIVE HYDRATION

複数のBrainを横断して読み、Claude APIに渡すコンテキストを組み立てる。これがVinのセットアップが手動でやっていること。

全ファイルを毎回投げない。frontmatter＋見出しのインデックスだけ常時ロードし、[[wikilink]] グラフを参照して、クエリに必要なファイルだけ全文展開する。Context Window を爆発させない設計。

L1

Schema

3層 × N Brain の構造定義。YAMLフロントマターの規約。どのファイルがIdentityで、どのファイルがLearningか。

L0

Storage

.mdファイル。Obsidianを使っても、ただのフォルダでも動く。データはすべてローカル。

各 Brain の解剖

すべての Brain は同じ3層構造を持つ。

Household BrainでもPerson Brainでも、内部構造は同じ。Identity（変わらないもの）、Learning（積み上がるもの）、Now（リアルタイムで計算されるもの）。

Identity

変わらない記憶

名前・アレルギー・価値観・家族構成。.mdのYAMLフロントマターに保存。

months – years

Learning

積み上がる記憶

購買履歴・好みの変化・過去の決断。.mdのボディに蓄積。

days – weeks

Now

今この瞬間

時刻・場所・物理状態。保存しない。呼び出し時にリアルタイム計算。

seconds – minutes

5 Brain Types（家族用）

Household Brain

家全体の記憶

予算・スケジュール・家のルール。家族全員が共有する土台。

Person Brain × N

1人1つの記憶

Hana、Sota、Kaiそれぞれ。個人の好み・アレルギー・習慣。

Domain Brain × N

領域ごとの記憶

食料品・スポーツ・医療など。ドメイン知識と過去の行動履歴。

Coordinator

調整する脳

複数のBrainを読み、矛盾を解消し、最適なコンテキストをClaudeに渡す。

Event Brain（使い捨て）

旅行・プロジェクト用

期間限定のBrain。終了後、学んだことをHousehold BrainまたはPerson Brainに書き戻す。

CH 03 · 01 — インストール

コマンド3つ。
5分で家族のBrainが立ち上がる。

Claude DesktopとNode.jsがあれば始められる。コードを書く必要はない。

1

インストール

Context Brain をグローバルインストール

npm install -g context-brain
2

セットアップ

ブラウザで家族構成を入力 → Brain 自動生成

ターミナルで質問攻めにせず、ローカルブラウザにウィザードが立ち上がる。世帯名・家族・ドメイン・Disclosure 初期値の4ステップ。Obsidian-ready な Vault が出力される（Obsidian アプリは任意）。

context-brain init # ✓ Brain フォルダを作成中... # ✓ http://localhost:5173 を開きました # ブラウザで家族構成を入力してください ↗

ウィザード 4 ステップ

Step 1 · 世帯 — 世帯名 / Vault 保存先
Step 2 · 家族 — 名前・年齢を「+追加」で何人でも
Step 3 · ドメイン — 食 / 掃除 / 買物 / 音楽 / 旅行（チェック）
Step 4 · Disclosure 初期値 — 各人 × 各ドメインの開示グリッド

# 出力される Obsidian-ready Vault my-brain/ identity/household.md # [[wikilinks]] 付き identity/people/sota.md # frontmatter に Disclosure learning/ # 蓄積層（空で開始） domains/sports.md .obsidian/ # 任意で Obsidian 起動可能 CLAUDE.md # Brain の読み方を記述
3

起動

MCP サーバーを起動して Claude Desktop に接続

context-brain start # MCP server running on stdio # Add to Claude Desktop: ~/.claude/settings.json
4

Claude Desktop 設定

settings.json に1行追加

// ~/.claude/settings.json { "mcpServers": { "context-brain": { "command": "context-brain", "args": ["start", "--stdio"] } } }

この後できること

Claude Desktop を開いて「今月の食費どう？」「Sota のサッカーシューズ何がいい？」と話しかけるだけ。Brain ファイルは ストレージ完全ローカル。ただし推論は Claude API を経由するため、Disclosure Dial で「何を Anthropic に渡すか」を per-domain × per-person で制御する。

V1 の Action Surface

Brain は read / write のみ。外部世界に対するアクションは行わない。

「お母さんに確認してから注文します？」に「はい」と答えると、Amazon の API は叩かれない。Household Brain の Learning Layer に tasks/pending.md として TODO が追記される。EC・カレンダー・スマートホームへの実アクションは V2 以降の MCP プラグインで提供。

完了の定義（V1）

Claude Desktop を開いて「靴どうしようかな」と入力する。

Context Brain が Household Brain（予算）× Person Brain · Sota（スポーツ・サイズ）を Selective Hydration で読み、Coordinator が統合し、Approval Gate（Confirm）付きで推薦を返す。「はい」で tasks/pending.md に TODO が書き込まれる。これが動いたら V1 完成。
