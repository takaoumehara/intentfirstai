Interpretation Preview

Assumption Cards — 前提を編集または棄却

いま起きたこと

Interpretation Preview は、AIが行動する前に現在の解釈を表示します。信頼度（confidence）と判定ドメインを見て、妥当かどうかを先に判断できます。

Assumption Cards は、AIが置いている前提を編集可能な形で見せます。編集可能カードはその場で書き換え、システム制約カードは読み取り専用です。棄却したカードは取り消し線で記録されます。

Confirm と Correct の分岐で、実行に進むか、交渉を再開するかが決まります。Confirm は Stage 6（Autonomy Resolution）へ、Correct は再解釈へ戻ります。

このデモでの Gate 発火ルール

表示するUI primitiveは confidence と domain で決まります。

  • R34 — Latent awareness → 常に仮説として交渉（直接実行しない）
  • R37 — confidence < 0.4 → Assumption Cards
  • R38 — 0.4 ≤ confidence < 0.8 → Interpretation Preview
  • R39 — confidence ≥ 0.8 + low risk + reversible → silent（通常はUIなし）

Phase 1 の範囲

このプロトタイプは Interpretation Preview と Assumption Cards を実装しています。Priority Toggle（価値衝突時の再ランキング）は Phase 2 の範囲です。

実装はルールベースです。Decision Schema の主眼は、モデル種別に依存せず推論契約を可視化することにあります。
