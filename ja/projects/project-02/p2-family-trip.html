Chapter 02 · 計画

旅が、現実になっていく。

Sarah がノートPCを開く。Takeshi が椅子を引き寄せる。子どもたちがソファ越しにのぞき込む。

AX Pattern · Intent Fidelity Check23 AX↗

ひとつの計画ではなく、
4つの方向。

Takeshi が言う—「京都、3週間、4人、$6,000」。Disposable Brain が起動し—旅程を1つ提示するのではなく、4つの方向を出す。それぞれが同じ意図の違う読み方だ。

バランス型 · 子ども中心アドベンチャー · 文化+祖父母 · ハイブリッド。Brain はまず、家族がどの「京都」を意味しているのかを確かめてから、そこにコミットしていく。

Takeshi（父・40歳）と Sarah（母・38歳）はハイブリッドをベースに選ぶ。ワンタップ。手作業での継ぎ合わせはない。

AX Pattern · Social-Aware FilteringAX · A3↗

Kai（息子・12歳）に値段は見えない。
いいとこだけが見える。

Kai がスマホを開くと、写真のデッキが並ぶ—忍者、刀鍛冶、ラーメン、アニメの博物館。値段も、所要時間も、雨の注意もない。「やりたい」か「たぶん」だけ。

Social-Aware Filtering は、親が引き受けるべきコンテキストを剥がす—予算、実現可能性、祖父母まわりの段取り。Brain は家族ひとりひとりに、その人が決めるべき部分だけを見せる。

AX Pattern · Social-Aware Filtering

Mia（娘・9歳）には、別のデッキが出る。

Home Brain は、Mia が「ものを作る子」だともう知っている。学校での陶芸、週末の折り紙、去年の夏の竹細工キット。彼女のデッキは工芸から始まる—陶芸、着物染め、食品サンプル作り、竹細工。

これは一般的な「子ども向けアクティビティ」ではない。この特定の9歳児が3年間示してきた好みから、Learning Layer をもとに組まれたものだ。

Kai との重なりがひとつ自動的に浮かび上がる—刀鍛冶。どちらの親が気づくより先に、Brain が「共通項」として印をつけている。

AX Pattern · Delegation LadderAX · A5↗

テレビには2つの案。
家族みんなで選ぶ。

木曜の夜。Brain が最有力の2案を、写真中心のカードとしてリビングのテレビに放る。値段も細かい注意書きもない—どちらも家族の予算と祖父母まわりの制約は満たしている。あとは、それぞれの旅の手触りだけ。

選ぶのは人間だ。Delegation Ladder はこう言っている—選択肢は AI が組むが、決めるのは親。「自動予約」はこの画面には出てこない。

User UI · TV 家族の夜 — テレビには写真中心の2つの案。子どもがどちらに身を乗り出すかを見て、親が選ぶ。

AX Pattern · Disclosure CascadeAX · A4↗

子どもはカウントダウンを見る。
親は予算を見る。

同じ旅、同じデータ—3つの面。親のスマホには費用の内訳と祖父母の移動手配。テレビには、子ども向けの写真中心カウントダウン:3日目に忍者、4日目に刀、8日目には祖父母と温泉。

理由は Disclosure Cascade。「出発まで12日」というひとつの事実を、受け手に合わせて3つの声に彫り分けている。

User UI · TV カウントダウン — 子ども向けビュー。冒険が写真のひと並びで流れる。値段も移動時間もない。

Chapter 03 · 発見

計画になかったもの。

Mia が竹の看板を見つける。午後のすべてが、そこから変わる。

AX Pattern · Proactive NudgeAX · A2↗

2日目・嵐山。
Mia が先に見つけた竹細工ワークショップ。

川から戻る道で、Mia（娘・9歳）が手書きの看板を見つける—竹細工・お立ち寄り OK。 聞く前に、Takeshi のスマホが鳴る—90分、ひとり¥2,500、14:30の枠が空いている、次に予約している錦市場（17:00）にもまだ間に合う。

Brain は予約しない。それとなく差し出す—実現可能 · 予算内 · ペース通り。家族は40秒で決める。Kai は午後を竹の刀で締めくくり、Mia は小さな花瓶を手にする。

Backstage · マッチングの舞台裏

6つのトークン × ひとつの Brain。
所要40秒。

このナッジは、家族には見えない交差点の出力だ。Mia の Learning Layer(工芸好き)。Physical State(14:00のエネルギー)。Feasibility(90分で収まる)。Priority Weight(次の予約に間に合う)。Social Exposure(観光客向けの英語表示)。Cognitive Load(親の負荷は今は低い)。

BACKSTAGE · Token 交差

Backstage view ゲージはそれぞれ8 Context Tokens のひとつ。嵐山の14:00に6つが揃った。それで十分だった。

AX Pattern · Graduated ArchiveAX · A8↗

その夜、アーカイブはひとつ。
相手は3組。

21:30、旅館にて。Disposable Brain がその日の写真アーカイブを3通りに下書きする。親向けには、ペースのメモと明日の段取り。京都の祖父母向けは日本語で、全写真つき。シアトルの祖父母向けにはベスト5枚が選ばれ、Sarah が「承認」をタップするのを待っている。

Graduated Archive — 同じ一日、3つの声、ひとつの家族。

AX Pattern · Per-Person Disclosure

京都の祖父母は、全部を見る。

Takeshi の両親はダイヤルを「フル共有」に設定している—全部の写真が見たい、食事の話も聞きたい。現地時間22:00に LINE に届く。日本語で、孫の名前は祖父母が呼んでいるとおりに(愛、海)。

セレクションもゲートもなし。Brain は、1日目に家族が設定した開示プロファイルをそのまま信じる。

AX Pattern · Per-Person Disclosure

シアトルの祖父母は5枚だけ。
Sarah が1枚ずつ承認する。

Sarah の両親は日本語を話さず、量が多いと疲れてしまう。彼らのダイヤルは「週1・厳選5枚・位置情報ピンなし」。毎週日曜、Brain から事前セレクションの5枚が届く。Sarah は2枚差し替え、承認し、送る。

同じ旅、同じ日、まったく違う「封筒」。それが per-person の本当の意味だ。

Chapter 04 · 雨

予報が変わる。計画が応える。

アウトドアの日の6時間前、雨が旅程を描き直す。

AX Pattern · Silent ResolutionAX · A6↗

3日目・07:00。
家族はまだ眠っている。

06:42、天気 API が反転する。3日目と4日目が「曇りのち晴れ」から「2日続きの大雨」に。07:00 には、Disposable Brain はもう屋外予約をスキャン済みだ—伏見稲荷(キャンセル)、着物散歩(5日目に延期)、竹林(2日目に済ませたので廃棄)。

屋内の予約がひとつ生き残る—忍者ワークショップ。07:30 に Sarah が目を覚ますと、通知は1件—「4日目まで雨。代替案を用意済み」。まだ何もキャンセルしていない。Brain は修復を準備しただけで、判断は親に渡っている。

Backstage · 代替案のランキング

候補は7つ。
残ったのは5つ。

Brain は各候補を4つの軸で重み付けする—屋内の確実さ、既存の忍者予約との相性、Kai と Mia のウィッシュリストとの重なり、祖父母の2日間訪問のペース。映画村は一部屋外—却下。水族館は割高で京都らしさが弱い—却下。三十三間堂、マンガミュージアム、市場、京都電鉄、食品サンプル作りが生き残る。

BACKSTAGE · 代替案ランキング
7つの選択肢、4つの軸、ひとつのショートリスト。

Backstage view 家族はこのマトリクスを開かない。生き残った5つを、写真カードとして見るだけだ。

AX Pattern · Live RecompositionAX · A7↗

3つの組み合わせ。
同じ5つの部品から。

Takeshi のスマホには、生き残った5つを2日間に配置し直す3通りが並ぶ。ゆったり—1日2スポット。詰め込み—1日5スポット、忍者の予約を10:30にずらす必要あり。マンガは後回し—1枚を次の雨の日のために温存。

同じ部品、3通りの組み立て方。Live Recomposition は、Brain が組み立てを「提案する」段階で、決めはしない。

AX Pattern · Care ArchitectureAX · A9↗

Kai が2つ選べたなら、
Mia にも2つ。

子どもたちが交渉する。Kai はマンガミュージアムと忍者ワークショップの両方がいい。Sarah はそっとスマホに言う—「Kai が2つなら、Mia も2つ。」 Brain が返すのは、食品サンプル作り(Mia のウィッシュリスト既収載)とその近くのタイル絵付けスタジオ—同じペース、同じ予算帯。

Care Architecture は、明示された公平さだ。Brain がルールを発明するのではなく、Sarah がルールを口にし、Brain がそれを二人の子どもに対して守り抜く。

いちばん大事な瞬間に。

Kai が発熱する。Autonomy が一段下がる。ケアが前に出る。

AX Pattern · Limitation DisclosureAX · A11↗

8日目、23:14。
Kai の熱が39.2℃まで上がる。

Sarah(母・38歳)は半分眠りかけている。Kai(息子・12歳)は熱で目を覚ます。Brain はこの1週間、ずっと「Auto」で動いてきた—予約、メニュー翻訳、写真アーカイブ。Sarah はひとつの動作で、Autonomy Dial を Confirm まで落とす。

Brain は別の声で応える。英語対応の夜間クリニック、1.4km、03:00まで営業中—マップを開く? · 受付用の症状リスト(翻訳済み)—見せる? · 京都の祖父母は15分の距離—電話する?

すべてのステップが、Sarah のタップのために浮上する。黙ってなにも送られない。Limitation Disclosure—クライシスでは、Brain が「自分はもう決めていない」と宣言する。

Concept · 開示を彫り分ける

同じ事実、3つの声。
設計された違いだ。

「Kai が熱を出した」は、3通りに出ていく。京都の Takeshi の母には、落ち着いた日本語の音声メッセージ—孫が熱を出している。近くの病院へ向かう。 シアトルの Sarah の両親には朝まで何も届かない—今夜できることはないし、眠れなくなるだけだから。隣の部屋で眠っている Mia(9歳)には、何も届かない。

1日目に設定された Disclosure Dial が、23:14に新しい判断を一切要らなくしている。

CONCEPT · 3つの声
23:14のひとつの事実。3つの封筒が自動的に守られる。

Concept · 開示を彫り分ける Brain は「誰に伝えるか」を決めていない。1日目のダイヤルを読んでいるだけだ。

Backstage · 3週間の Autonomy

Autonomy Dial は6回動いた。
家族はほとんど気づいていない。

計画期:Suggest(すべての選択肢がテーブルの上)。出発前週:Confirm(Brain が下書き、Sarah がタップ)。旅の中盤の既定:Auto(レストラン再予約、写真アーカイブ)。雨の修復:Confirm(旅程は親が決める)。発熱の夜:Notify + Confirm(すべてのステップが見える)。帰りの機内:Suggest に戻る。

あらゆる移動を駆動したのは3つの力—サービスの既定値 × Brain の調整 × Sarah の能動的な選択。 Autonomy は決してユーザー単独のコントロールではなく、Brain は変化のたびに現在のレベルを見えるようにする。

BACKSTAGE · Autonomy タイムライン
21日間で6回の段階移行。家族が明示的に見たのはそのうち2回。

Backstage view Autonomy は設定ではなく、動詞だ。Brain が動かし続け、重要なときは動きを宣言していた。

Backstage · 記憶の吸収

帰りの機内で、
Disposable Brain は畳み込まれる。

巡航高度で、Disposable Brain は最後の仕事に取りかかる。この家族について学んだことをデルタ(差分)にまとめ、Home Brain に追記する。そして、自分を削除する。

残るのはこんなことだ—Kai はとんこつラーメンが好き。Mia は30分ではなく90分の工芸ブロックがいい。Takeshi の父の実際の徒歩限界は20分ではなく18分。Sarah は9階以上の部屋を好む。家族の音量は旅の7日目以降、急に落ちる。家族は知識が6つ分、賢くなった—次の旅のツールは、そこから始まることになる。
