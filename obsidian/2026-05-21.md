# P4 Atlas typography and shell consistency fix

## Problem
Project 04 Atlas screens were conceptually aligned with the master plan, but several core screens still rendered 9px to 12px local typography. In practice this broke readability and made the product feel like multiple related prototypes instead of one Atlas system.

## Cause
- `atlas-ui.css` was not reliably winning the cascade on several screens because it was loaded before local `<style>` blocks.
- `p4-compact.html` still contained many host-page labels, captions, and workflow cards with undersized copy.
- Shared Atlas typography overrides did not cover enough component classes across command, evidence, and monitor surfaces.

## Fix
- Moved `atlas-ui.css` to load after local `<style>` blocks in Atlas screens so the shared system wins the cascade.
- Expanded `assets/css/atlas-ui.css` typography coverage across portfolio, proposal review, evidence, and monitor surfaces.
- Raised host-page explanatory typography in `projects/project-04/p4-compact.html` so captions, workflow cards, backstage labels, timeline cards, and policy notes meet the readability target.
- Kept Brain terminology demoted into scope/provenance while preserving Atlas as the visible product layer.

## Atlas shell nav fix
- Added visible icon-plus-label product navigation to core Atlas screens.
- This corrects a design miss where the interfaces looked like static information boards rather than a real tool with product-level IA.
- Shared navigation is implemented in `assets/css/atlas-ui.css` and applied in portfolio, review, evidence, archive, and monitor screens.

## Linear/Vercel visual system refactor
- Promoted Geist to the first-choice UI font in shared tokens.
- Refactored Atlas shared surfaces from warm beige enterprise styling to a neutral white/gray system with black controls and restrained blue/violet accents.
- Updated `p4-compact.html` and `p4-scroll-v4.html` outer story surfaces to match the same visual language.
- Patched backstage/model screens to remove remaining warm brown accents from the old palette.

## Linear Dark Atlas Refactor
- Reference switched to `DESIGN.md`.
- Atlas UI screens now use near-black canvas `#010102`, surface ladder `#0f1011` → `#191a1b`, and single lavender accent `#5e6ad2`.
- Warm ochre/orange accents were removed from `atlas-ui.css`, `pmb-dashboard.html`, `pmb-conversation.html`, `p4-scroll-v4.html`, and `p4-compact.html`.
- Product shell intent: Linear-style dark application chrome, hairline borders, restrained accent usage, no atmospheric warm gradients.
